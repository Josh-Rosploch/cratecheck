Step-by-Step Setup (Takes ~3 Mins)

All keys stay strictly on your phone in localStorage and never touch any third-party server.

1. Get Your Gemini API Key (For Photo Scanning & Taste AI)

  1. Open Google AI Studio (aistudio.google.com/apikey) and sign in with Google.
  2. Tap Create API Key, select or create a project, and copy the key starting with AIza....
  3. Paste it into Settings → Gemini API Key and tap Save.

2. Get Your Discogs Token (For Collection & Prices)

  1. Log into Discogs and open discogs.com/settings/developers.
  2. Tap Generate new token and copy it.
  3. Paste it into Settings → Discogs Personal Access Token, then tap Verify Account & Load Folders to pick which folder new scans go into.
  4. Tip for VG+ estimates: Discogs only returns VG+ price suggestions if you have a default seller currency set in Discogs Seller Settings—otherwise the app cleanly uses Lowest Listed Price + Scarcity.

3. Connect Spotify (For "Would I Like This?")

  1. Copy your app's exact Redirect URI below:
  2. Open developer.spotify.com/dashboard (requires your Spotify Premium account).
  3. Tap Create app → name it CrateCheck → paste the Redirect URI above → check Web API → Save.
  4. Open your app's Settings, copy the Client ID (you do NOT need the Client Secret).
  5. Paste the Client ID into Settings → Spotify Client ID and tap Connect & Sync Spotify.

4. Install as a Home-Screen App on Android

  1. Open your GitHub Pages URL in Chrome on your phone.
  2. Tap the ⋮ menu (top-right) → Add to Home screen → Install.
  3. It now launches full-screen like a native app and works on 5G at Goodwill.
