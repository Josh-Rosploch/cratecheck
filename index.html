Best Cataloging Workflow & Setup

Recommended 2-Photo + UPC Loop

  1. Lay cassette Side A next to front of box → tap 📷 Front / Side A.
  2. Flip both over (Side B + back of box) → tap 📷 Back / Side B.
  3. Tap ║▌ Scan UPC if there's a barcode, then tap 🔍 Search & Analyze.
  4. If the AI graded too generously (or missed playback issues), tap 🎤 Don't Agree? AI Voice Re-Grade and describe the flaws out loud—AI will pick the Discogs grades and rewrite the condition note for you.

API Setup Links

  1. Gemini Key: aistudio.google.com/apikey → Create API Key → paste in Settings → Test.
  2. Discogs Token: discogs.com/settings/developers → Generate token → tap Verify Account & Load Folders (also maps your Media/Sleeve/Notes fields).
