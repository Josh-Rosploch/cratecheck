Best Photo Trick for Exact Pressing ID

  1. For cased cassettes, lay the cassette shell next to the J-card in one photo (showing shell color, timing window, and printed text/barcode).
  2. The AI Variant Detective automatically reads Discogs pressing notes and compares them to your photo—or asks you 1 quick Yes/No question to lock down the exact edition.

1. Gemini API Key

  1. Open Google AI Studio → Create API Key → paste in Settings → tap 🧪 Test Gemini Key.
  2. Google AI Pro subscribers: You can also claim $10/month in Gemini API credits inside AI Studio's Billing/Plans menu.

2. Discogs Token & Folders

  1. Open discogs.com/settings/developers → Generate new token → paste in Settings → tap Verify Account & Load Folders.
  2. Create custom folders anytime at discogs.com/manage_folders, then tap Verify again.
